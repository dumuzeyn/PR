# Безопасность UZYRO

## Модель безопасности

UZYRO считает недоверенными изображения, RAW, PSD/PSB, проекты PRDX, ICC/ASE, пресеты, Actions, batch-очереди, плагины, Smart Object и загружаемые файлы локальных моделей. Проверки выполняются на границах открытия, импорта, загрузки, распаковки и запуска процесса, а не в горячем пути рендеринга.

Центральный пакет `uzyro.security` отвечает за:

- канонизацию путей и запрет Windows device paths, traversal, архивных symlink и выхода из целевой папки;
- лимиты размеров файлов, изображений, кадров, слоёв, JSON, архивов, плиток, IPC и вывода процессов;
- проверку конечности чисел и глубины/числа элементов JSON;
- безопасное чтение Pillow-изображений и ZIP без `extractall`;
- прямой запуск исполняемых файлов без shell, с таймаутом и ограничением вывода;
- HTTPS allowlist для core-загрузок и loopback-only адреса локального AI.

PRDX проверяет структуру манифеста, размеры, типы массивов, пути и SHA-256 плиток до выделения основных массивов. PSD/PSB проверяет заголовок, размеры и число слоёв перед импортом. Повреждённый или чрезмерный вход отклоняется без изменения пользовательских файлов.

## Плагины

Разрешения плагинов запрещены по умолчанию. Manifest, ID и entrypoint проходят проверку; entrypoint должен быть обычным `.py` внутри папки плагина. Legacy-плагин без manifest также не запускается до явной выдачи `pixels`.

Уровни возможностей:

- `pixels`: работа с переданными пикселями;
- `document`: изменение структуры документа;
- `filesystem.read` / `filesystem.write`: доступ к файлам;
- `network`: сеть;
- `process`: запуск процессов;
- `native`: загрузка нативного кода.

Плагин работает в отдельном процессе с JSON/NPY IPC, ограничением сообщения, времени и вывода. Python audit hook блокирует операции без разрешения, но **не является системной песочницей**. Плагин с `process` или `native` следует считать доверенным кодом пользователя. UZYRO не устанавливает плагины автоматически.

## Локальные модели

UZYRO не отправляет изображения или промпты в облачный AI. Модели и `stable-diffusion.cpp` загружаются только по HTTPS с разрешённых хостов, с опубликованным размером и SHA-256. Архив движка проверяется до распаковки, а SHA-256 установленного executable сверяется перед использованием.

Локальный сервер запускается на случайном порту и слушает только `127.0.0.1`. Используемый upstream server не поддерживает обязательный token для своего API, поэтому UZYRO не заявляет аутентификацию, которой нет. Сервер завершается при отмене, смене конфигурации и выходе из приложения.

## Сеть и данные

В core нет телеметрии, аналитики и автоматической отправки документов, EXIF, путей или буфера обмена. Сеть используется только для явной установки локальных моделей. Сетевой доступ плагина отделён разрешением `network`.

## Ограничения

Pillow, OpenCV, rawpy, LittleCMS и psd-tools содержат нативные декодеры и работают в процессе приложения. Структурные и ресурсные проверки уменьшают поверхность атаки, но не заменяют исправления безопасности этих библиотек. Зависимости закреплены, а CI запускает `pip-audit`; обновления безопасности должны устанавливаться без задержки.

Очень большой корректный документ может быть отклонён, если его оценка памяти превышает динамический бюджет доступной RAM. Это преднамеренная защита от аварийного исчерпания памяти.
