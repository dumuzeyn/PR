## About UZYRO

UZYRO brings photo editing, painting, typography, and vector artwork into one layered project. Raster content can live beside editable shapes and text, masks, adjustment layers, filters, and Smart Objects without flattening the entire composition.

The interface is organized around the canvas: named tools and visual demonstrations are on the left, contextual options are above, and layers, properties, and history are on the right. A separate start screen provides direct access to new documents, project opening, session recovery, and recent work.

## Getting Started

<p align="center">
  <img src="docs/screenshots/01-start-screen.png" width="900" alt="UZYRO start screen">
</p>

New documents include screen and print presets plus reusable custom dimensions. UZYRO displays every preset's proportions, remembers custom values, and offers a clipboard-image preset when an image is available.

The EXE is built automatically. Select **Download Windows build**, open the latest successful **Build UZYRO for Windows** run, then download the **UZYRO-Windows** artifact containing `UZYRO.exe`.

## Workspace

<p align="center">
  <img src="docs/screenshots/02-workspace.png" width="1200" alt="UZYRO workspace with editable text and vector layers">
</p>

Documents open centered, and zooming preserves the current image area. The tool panel can be reordered by dragging. Every tool includes its name, parameter guidance, and an animated demonstration produced with real UZYRO operations.

## Painting and Retouching

<p align="center">
  <img src="docs/screenshots/03-painting.png" width="1200" alt="Painting with a brush in UZYRO">
</p>

The shared brush engine powers painting, erasing, and local image processing. It supports custom tips and presets, hardness, flow, smoothing, spacing, and pen dynamics. History records changed stroke regions instead of copying the complete document after every pointer movement.

Retouching includes Clone Stamp, Healing Brush, Spot Healing, Patch, Frequency Separation, local Blur and Sharpen, Dodge, and Burn. These tools respect the active selection and layer mask.

## What Sets UZYRO Apart

- **Non-destructive editing.** Adjustment layers, editable filters, filter masks, layer styles, and Smart Objects remain configurable after they are applied.
- **Precision selections.** Quick Selection, Magic Wand, Color Range, Magnetic Lasso, and the Select and Mask workspace preserve soft alpha and support edge refinement.
- **Raster, vector, and text together.** Shapes, Bezier paths, text on a path, and transforms retain editable project data in `.prdx`.
- **High-precision color.** The pipeline supports 8/16/32-bit working data, RAW, ICC profiles, soft proofing, gamut warnings, and CMYK/Spot output preparation.
- **Large-document architecture.** Tile rendering, bounded caches, background loading, and compact history reduce latency and memory use.
- **Automation and extensibility.** Actions, persistent batch queues, and isolated plugins complement manual editing. Optional local generative models install separately and keep documents off cloud services.

## Formats and Compatibility

The `.prdx` format preserves layers, masks, vector data, text, effects, and document structure. UZYRO supports PNG, JPEG, WebP, BMP, TIFF, and RAW, plus layered PSD/PSB import and export.

UZYRO does not claim an impossible &#8220;perfect&#8221; PSD round trip. Photoshop structures that supported open libraries cannot write back as editable data are rasterized and listed in the export report.
