# Архитектура UZYRO

## Поток изменений

Редактирование проходит по единому маршруту:

```text
действие пользователя
  -> команда редактора
  -> модель Document и Layer
  -> RenderEngine
  -> холст, слои, свойства и история
```

Положение, размеры, поворот, видимость и свойства фигуры хранятся только в
соответствующем `Layer`. Bounding box и точки управления каждый раз вычисляются
из состояния слоя. Холст не хранит отдельную копию фигуры.

Во время перемещения и трансформации модель получает временное состояние с
ограниченным обновлением холста. При отпускании кнопки мыши создаётся одна
компактная команда истории с состояниями до и после операции.

## Выбор объектов

`object_hit_testing.py` является общей точкой hit-test для выбора, наведения и
переключения перекрывающихся объектов. Проверка идёт от верхнего видимого слоя к
нижнему и учитывает блокировку. Обычный клик выбирает верхний объект, `Alt + клик`
переходит к следующему объекту под ним, `Shift + клик` изменяет групповой выбор.

Выбранные фигуры остаются обычными слоями. Общая рамка нескольких объектов не
создаёт дополнительной сущности и строится по актуальной геометрии выбранных
слоёв.

## Документы

`DocumentManager` владеет списком `DocumentSession` и идентификатором активного
документа. Сессия хранит:

- модель документа и слои;
- собственную историю;
- выбранные слои;
- масштаб и положение рабочей области;
- поколение фонового редактирования;
- путь и признак несохранённых изменений через `Document`.

Переключение вкладки подменяет только активную сессию в интерфейсе. Документ не
пересоздаётся, поэтому история, выделение и вид сохраняются независимо. Закрытие
изменённой вкладки и выход из приложения проходят через один механизм проверки
несохранённой работы.

## Границы модулей

- `document_manager.py` управляет жизненным циклом открытых документов.
- `object_hit_testing.py` отвечает за поиск объектов и рамочное выделение.
- `direct_manipulation.py` управляет фигурами и общими трансформациями.
- `selection_move_preview.py` показывает быстрое перемещение пиксельного выделения.
- `history_base.py` хранит компактные команды undo/redo.
- `shape_ops.py` рендерит векторные свойства слоя в пиксельное представление.
