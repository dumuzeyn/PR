# Источники демонстраций инструментов

Изображения `design_assets/tool_demo_sources/still_life.png` и `design_assets/tool_demo_sources/landscape.png` созданы специально для UZYRO. Сторонние фотографии, логотипы, водяные знаки и работы конкретных художников не использовались.

Кадры демонстраций формируются скриптом `scripts/build_tool_demos.py`. Рисование, стирание, ретушь, клонирование, лечение, заплатка, заливка, градиент, текст, фигуры, контуры, выделения и кадрирование выполняются рабочими движками UZYRO. Pillow используется только для курсора, служебных рамок, подписей и упаковки кадров в GIF.

Файл `manifest.json` хранит версию генератора, контрольные суммы исходных изображений и перечень инструментов. Каждый GIF также содержит метку `UZYRO actual tool engine v1`.
