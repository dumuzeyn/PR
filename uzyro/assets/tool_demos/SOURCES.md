# Источники демонстраций инструментов

Файлы `design_assets/tool_demo_sources/still_life.png` и `design_assets/tool_demo_sources/landscape.png` созданы 10 августа 2026 года встроенным генератором изображений OpenAI специально для UZYRO. Сторонние фотографии, логотипы, водяные знаки и работы конкретных художников не использовались.

Анимированные GIF-файлы построены локально скриптом `scripts/build_tool_demos.py` с помощью Pillow. Они предназначены только для подсказок инструментов и могут быть воспроизведены без сети.
