# Ручная проверка инструментов PhotoRedactor

Статус `Авто` означает, что поведение покрыто автоматическим тестом. Статус `Ручная` требует визуального сравнения в собранном приложении и Photoshop на одном исходнике.

| Tool | Scenario | Expected Result | Status |
|---|---|---|---|
| Brush | 100 px, Hardness 0%, Opacity 100%, Flow 10%; медленная линия | Мягкая непрерывная линия, насыщенность плавно растёт от перекрытия dab | Ручная |
| Brush | Одинаковая линия при частоте событий 60 и 240 Гц | Геометрия и насыщенность практически совпадают | Авто |
| Brush | Spacing 1%, 25%, 100% | Интервал меняет частоту отпечатков относительно диаметра | Авто + ручная |
| Brush | Multiply, Screen, Overlay, Darken, Lighten | Цвет смешивается по выбранному режиму, alpha корректна | Авто + ручная |
| Brush | Smoothing 0% и 80% на медленной волнистой линии | При 80% мелкая дрожь уменьшается без большой задержки | Ручная |
| Brush | Давление пера для Size, Opacity и Flow | Каждый включённый параметр независимо реагирует на нажим | Авто + ручная с пером |
| Brush | Сохранить, выбрать и удалить пользовательский пресет | Восстанавливаются только настройки кисти; стандартные пресеты защищены | Ручная |
| Eraser | Стереть цветной участок на прозрачном слое | Меняется alpha, скрытые RGB не становятся чёрными | Авто |
| Eraser | Стирание при активном выделении | Пиксели вне выделения не меняются | Авто + ручная |
| Blur | Strength 10%, 50%, 100% по текстурной области | Эффект растёт постепенно, 10% не уничтожает детали за проход | Авто + ручная |
| Blur | Три прохода Strength 50% | Каждый новый штрих усиливает локальное размытие | Авто |
| Blur | Мазок у края изображения | Нет тёмной каймы, ошибки или изменения вне кисти | Авто + ручная |
| Sharpen | Strength 10%, 50%, 100% на контрастной границе | Резкость нарастает без мгновенных белых/чёрных ореолов | Авто + ручная |
| Sharpen | Медленный и быстрый одинаковый штрих | Результат не зависит радикально от числа MouseMove | Авто |
| Clone Stamp | Aligned ON/OFF; Current Layer / Current & Below / All Visible; Scale X/Y, Rotation, Flip X/Y | Источник продолжает смещение только при Aligned ON; наложение до мазка совпадает с преобразованным результатом | Авто + ручная |
| Healing Brush | Точка на коже, гладкий фон и граница света/тени; Opacity/Flow 20% и 100% | Высокочастотная текстура переносится, тон адаптируется без круглого края источника | Авто + ручная |
| Spot Healing | Оба режима на пятне и царапине на однородном и текстурном фоне | «Соответствие окружению» и «С учётом содержимого» дают разные результаты; дефект уменьшается, край остаётся мягким | Авто + ручная |
| Patch | Structure 1/7, Color Adaptation 0/10, Sample All Layers, Escape, Enter и кнопка «Применить» | Параметры заметно меняют результат; до подтверждения документ неизменен; Escape отменяет; применение создаёт один плиточный Undo | Авто + ручная |
| Selection | Rectangle, ellipse, lasso, polygon; Add/Subtract/Intersect | Маска сохраняет реальную форму и режим объединения | Авто + ручная, Phase 3 |
| Magic Wand | Contiguous ON/OFF, Anti-alias ON/OFF, Current Layer/All Layers | Связность и источник меняют результат; сглаживание создаёт только мягкий край | Авто + ручная, Phase 3 |
| Color Range | Новый образец, Shift-добавление, Ctrl-вычитание, Fuzziness 0–128 | Предпросмотр обновляется, несколько цветов объединяются, вычтенный цвет исчезает, мягкая alpha сохраняется | Авто + ручная, Phase 3 |
| Quick Selection | Add/Subtract, разные размеры кисти и сила привязки | Рост следует локальному объекту и останавливается на контрастных границах | Авто + ручная, Phase 3 |
| Automatic Selection | Объект, ROI-объект, фон и небо; CPU и локальная ONNX-модель | ROI не захватывает похожий объект снаружи; backend/fallback показан, модель сама не скачивается | Авто + ручная, Phase 3 |
| Select and Mask | Все режимы просмотра, Smart Radius, кисть волос, четыре варианта вывода | Тонкие и полупрозрачные края не бинаризуются; результат и Undo соответствуют выбранному выводу | Авто + ручная, Phase 3 |
| Gradient | Все пять типов, 3+ цветовые точки, отдельные точки alpha, midpoint, reverse, dithering | Маркеры перетаскиваются; preview совпадает с применённым результатом; прозрачность и midpoint реально меняют переход | Авто + ручная, Phase 4 |
| Gradient Object | Создать эллипс с градиентом, изменить тип, угол, масштаб и точки после создания | Фигура не растрируется; каждое изменение сразу видно и отменяется | Авто + ручная, Phase 4 |
| Shapes | Rectangle/Ellipse/Polygon/Star с Shift, Alt, скруглением, inside/center/outside stroke, opacity и rotation | Предпросмотр совпадает с итогом; свойства меняются на холсте без технических строк координат | Авто + ручная, Phase 4 |
| Paths | Выбрать контур и несколько узлов, двигать anchor/handles, Alt-развязка, добавить/удалить/преобразовать узел | Контур меняется непосредственно на холсте; сетка привязывает точки; один drag создаёт один Undo | Авто + ручная, Phase 4 |
| Move | Auto-Select Layer/Group/Off, группа из 3 слоёв, 60 слоёв в документе | Выбирается ожидаемый слой или вся группа; Off двигает активный слой; группа движется плавно и отменяется одним действием | Авто + ручная, Phase 4 |
| Text | Kerning, H/V Scale, Baseline Shift, underline/strike, Justify, indents, spacing, Vertical Type | Все параметры визуально различимы, сохраняются после открытия проекта, текст остаётся редактируемым | Авто + ручная, Phase 4 |
| Text on Path | Изменить текст и типографику после размещения на кривой, сменить сторону и направление | Символы остаются на касательной, декорации следуют контуру, данные не растрируются | Авто + ручная, Phase 4 |
| Warp | Сетки 3x3, 4x4 и пользовательская | Cancel возвращает исходник; Apply создаёт один Undo | Ручная, Phase 5 |
