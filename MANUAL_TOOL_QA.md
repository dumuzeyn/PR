# Ручная проверка инструментов PhotoRedactor

Статус `Авто` означает, что поведение покрыто автоматическим тестом. Статус `Ручная` требует визуального сравнения в собранном приложении и Photoshop на одном исходнике.

| Tool | Scenario | Expected Result | Status |
|---|---|---|---|
| Brush | 100 px, Hardness 0%, Opacity 100%, Flow 10%; медленная линия | Мягкая непрерывная линия, насыщенность плавно растёт от перекрытия dab | Ручная |
| Brush | Одинаковая линия при частоте событий 60 и 240 Гц | Геометрия и насыщенность практически совпадают | Авто |
| Brush | Spacing 1%, 25%, 100% | Интервал меняет частоту отпечатков относительно диаметра | Авто + ручная |
| Brush | Multiply, Screen, Overlay, Darken, Lighten | Цвет смешивается по выбранному режиму, alpha корректна | Авто + ручная |
| Brush | Smoothing 0% и 80% на медленной волнистой линии | При 80% мелкая дрожь уменьшается без большой задержки | Ручная |
| Brush | Давление пера для Size, Opacity и Flow | Каждый включённый параметр независимо реагирует на нажим | Авто + ручная с пером |
| Brush | Сохранить, выбрать и удалить пользовательский пресет | Восстанавливаются только настройки кисти; стандартные пресеты защищены | Ручная |
| Eraser | Стереть цветной участок на прозрачном слое | Меняется alpha, скрытые RGB не становятся чёрными | Авто |
| Eraser | Стирание при активном выделении | Пиксели вне выделения не меняются | Авто + ручная |
| Blur | Strength 10%, 50%, 100% по текстурной области | Эффект растёт постепенно, 10% не уничтожает детали за проход | Авто + ручная |
| Blur | Три прохода Strength 50% | Каждый новый штрих усиливает локальное размытие | Авто |
| Blur | Мазок у края изображения | Нет тёмной каймы, ошибки или изменения вне кисти | Авто + ручная |
| Sharpen | Strength 10%, 50%, 100% на контрастной границе | Резкость нарастает без мгновенных белых/чёрных ореолов | Авто + ручная |
| Sharpen | Медленный и быстрый одинаковый штрих | Результат не зависит радикально от числа MouseMove | Авто |
| Clone Stamp | Aligned ON/OFF | Источник продолжает смещение только при Aligned ON | Ручная, Phase 2 |
| Healing Brush | Точка на коже и граница света/тени | Текстура переносится, тон адаптируется без круглого края | Ручная, Phase 2 |
| Spot Healing | Дефект на однородном и текстурном фоне | Источник выбирается вокруг дефекта, край незаметен | Ручная, Phase 2 |
| Patch | Перемещение источника, Escape, Enter | До Enter только preview; Escape отменяет; Enter создаёт один Undo | Ручная, Phase 2 |
| Selection | Rectangle, ellipse, lasso, polygon; Add/Subtract/Intersect | Маска сохраняет реальную форму и режим объединения | Авто + ручная, Phase 3 |
| Gradient | Все пять типов, несколько stops, reverse | Preview совпадает с применённым результатом | Авто + ручная, Phase 4 |
| Warp | Сетки 3x3, 4x4 и пользовательская | Cancel возвращает исходник; Apply создаёт один Undo | Ручная, Phase 5 |
